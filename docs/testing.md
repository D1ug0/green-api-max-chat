# Ручная проверка

## Без аккаунта: деморежим

- Открыть приложение, убедиться, что пустые данные не позволяют подключиться.
- Нажать «Попробовать демо», проверить видимую маркировку режима.
- Убедиться, что список личных чатов пуст. Нажать «Создать первый чат» и добавить номер.
- Отправить текст по Enter и кнопкой. Должны появиться одна исходящая запись и один демонстрационный ответ.
- Использовать Shift + Enter: перенос должен остаться в поле ввода.
- Переключить чат с незавершённым черновиком: в списке возле него должна появиться пометка «Черновик» с началом текста. Вернуться: черновик должен сохраниться. Очистить поле: пометка должна исчезнуть.
- Создать ещё один чат с неверным номером: увидеть понятную ошибку. С корректным форматированным номером открыть диалог.
- Повторно открыть тот же номер: второй чат не создаётся.
- Проверить поиск по имени и номеру, отсутствие результатов, очистку поиска.
- Открыть модальное окно с клавиатуры: фокус в поле номера, Tab остаётся внутри окна, Escape закрывает его.
- Проверить ширины 390, 768 и 1366 px. На узком экране список и переписка открываются по очереди; стрелка возвращает к списку.
- Отправить длинную строку без пробелов: она переносится внутри сообщения. Текст длиннее 4000 символов не отправляется.
- Обновить историю: сообщения не удваиваются.
- Отключиться: вернуться к форме подключения, очистить данные сессии и черновики.

## С реальным MAX-инстансом

1. Подключить подготовленный инстанс, проверить выбранный `apiUrl` и пустой список чатов.
2. Открыть личный чат по номеру второго аккаунта MAX.
3. Отправить текст, убедиться в получении на телефоне.
4. Ответить с телефона текстом и сообщением со ссылкой. Оба должны появиться в том же диалоге.
5. Проверить поступление уведомлений статуса при включённых исходящих уведомлениях.
6. Написать черновик, обновить страницу. Подключение, список добавленных чатов, выбранный чат и черновик восстанавливаются автоматически; доступная история сообщений загружается из API без дублей.
7. Нажать «Выйти» и обновить страницу: должен открыться экран ввода данных инстанса, а список и черновики не должны восстановиться после нового входа.
8. На время отключить сеть: увидеть восстановление соединения, затем проверить продолжение получения.
9. Попробовать отправку во время сбоя: текст остаётся в истории с ошибкой или неопределённым статусом, автоматического повтора нет.
10. Открыть тот же инстанс во второй вкладке. Она ожидает освобождения очереди; после закрытия первой начинает получение.
11. Проверить неподдерживаемое уведомление (например, изображение): последующий текст продолжает поступать.

Автоматические тесты используют изолированные хранилища и подменённый HTTP-транспорт. Они не отправляют запросов или сообщений в реальный MAX.
